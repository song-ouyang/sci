# Claude reported summary: post-report archival supplement

This folder preserves the user-supplied nine-cell mean/SD summary and the 27
prediction arrays inspected when it was received. It is not a new inference run,
a pre-score freeze, or a validated classification-score release.

- `reported_summary.json`: exact reported numeric values. SD convention unknown;
  missing F1 SDs remain null. Values have not been recomputed against answers.
- `artifact_snapshot/`: copied requests, responses, predictions, metadata and
  historical protocol/schedule/source manifest, with original files unchanged.
- `snapshot_manifest.json`: hash inventory captured AFTER the supplied summary;
  it cannot certify historical answer isolation or inference provenance.
- `artifact_checks.json`: label-free checks regenerated by
  `python src/analysis/render_claude_reported_summary.py`.

All 27 arrays are structurally valid; 23 current local request/response/prediction
chains are consistent. None is certified for controlled primary scoring. The
Fable metadata uses `model_alias: opus`, with native model identity unavailable.
Opus clean/corrupted prediction flips are 0/70 in all three paired repeats;
Fable flips are 6/70, 3/70, 0/70. The blanket Fable invariance/perfect-score claim
therefore conflicts with this snapshot. No ground-truth files are opened by the
supplement generator, and no classification scores are computed from invalid
batches. Existing fail-closed primary scores remain N/A.

Paper Appendix B and Table 14 retain the reported values with these limitations.
Do not cite the table as a validated model ranking or evidence of exclusive
numerical reliance. The 129 controlled requests and 130 independent source units
remain unchanged. Potential ongoing agents or later file updates are not used
as evidence of completed, isolated sessions; this report covers the saved bytes.
